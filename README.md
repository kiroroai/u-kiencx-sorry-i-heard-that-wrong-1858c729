Entry for the [make.fun](https://make.fun) competition
[Sorry, I Heard That Wrong](https://make.fun/c/u-kiencx-sorry-i-heard-that-wrong-1858c729):
a single line of at most 140 characters — the apology a smart speaker
gives its owner after mishearing them.

## Run

```sh
python3 main.py
```

`main.py` writes one line to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The line is a fixed
literal: deterministic, no randomness, no clock, no network.

## Entry

> Sorry — I heard ‘lock the door’ as ‘talk to the door,’ so I’ve spent
> ten minutes negotiating with it. It hasn’t said a word.
